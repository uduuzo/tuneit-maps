TuneiT maps, Intergalactic Ball. Designed by Uzo Udu, UZO Media Productions.

Three files make the whole site: index.html (start page), cloister.html, visiting.html. No server code, no build step.

GitHub Pages: put these files at the top level of a public repository, then Settings > Pages > Deploy from a branch > main, folder / (root) > Save. The site appears at https://<your-user>.github.io/<repository>/ within a minute or two.
Any other static host (Netlify, Cloudflare Pages, Vercel, your own web space) works the same way: upload the folder.
